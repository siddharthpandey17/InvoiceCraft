# InvoiceCraft — Invoice Generator

A responsive invoice editor with a live preview, built using HTML, CSS and vanilla JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Complete the JavaScript TODOs in `js/script.js`.

## Challenges
- [ ] Read line items into an array of objects.
- [ ] Calculate subtotal, tax, discount and grand total.
- [ ] Render invoice line items dynamically.
- [ ] Sync editor fields with the preview.
- [ ] Add and remove line items.
- [ ] Update preview live while typing.
- [ ] Implement print/export.
